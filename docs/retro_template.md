# Project retrospective template

Copy this section into a local retrospective after validation.

## Retro

- Project: `<repository>__<topic>`
- What changed: `<short summary>`
- What went well: `<evidence>`
- What was difficult: `<evidence>`
- Follow-up: `<owner-neutral action>`
- Deletion ratio: `<removed lines> removed / <added lines> added = <percentage>%`

If no lines were removed, write:

```text
Deletion ratio: none (0 lines removed; no deletion work)
```

The ratio is descriptive evidence, not a quality threshold. Validate the completed artifact with the repository-local governance checker.
