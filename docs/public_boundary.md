# Public source boundary

Public main is the development and source authority. Project ordinary product source and portable tests as a content diff onto public; preserve public-only changes. Before every public push run the existing residue/private-data/history guard and the repository gates in [repo_workflow.md](repo_workflow.md).

The historical-boundary first batch publishes envelope helpers, an explicitly configured hub client, opt-in dashboard adapters, product icons, pure audio buffer/wake-queue helpers, parser and hermetic tests. The existing app entry and dashboard activation are unchanged. Business and foreclosure registration requires a configured hub or configured remote client; scraper embedding requires `HOST.dashboardHubConfig.scraperBotUrl`. Specs takes its identity from `cc.getConfig()` and the existing host presentation helper, never an OS-name guess. Shared-board adapters support an unavailable notice or a supplied shared-board implementation; the private vendor wiring is not shipped. These source changes do not activate dashboards or claim runtime delivery.

Keep actual host configuration, credential/token contents, captured transcripts/screens, raw run evidence, private dependency wiring and live-host/device deployment orchestration private. Generic test or helper code is reviewed by content and dependency closure, not by directory name. The audio test file includes pure buffer cases; listener/server/CLI integration cases remain with their retained private subjects.

Portable checks use synthetic data and owned temporary resources. Run `node --test test/public_dashboard_adapters.test.js test/business_envelope.test.js`, and with NumPy/pytest installed run `PYTHONPATH=mic-server python3 -m pytest mic-server/test/test_audio_buffer.py mic-server/test/test_wake_capture.py test/test_specs_parser.py`. The hub-client check uses an ephemeral loopback WebSocket and a temporary cache/token file, then tears them down. The service merge gate owns its isolated daemon/tmux resources. No fleet runtime, microphone or live host is involved.
