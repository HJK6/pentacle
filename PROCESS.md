# Pentacle processes

Pentacle's development process combines written specs, direct implementation, independent QA and evidence tied to the artifact being tested. You can adopt it for a single project or use Pentacle to coordinate multiple agents.

- Start with [process setup](process/README.md) to create and validate a spec workspace.
- Give your coding agents the root [AGENTS.md](AGENTS.md).
- Follow the [development lifecycle](process/docs/config/development_process.md), [QA guidelines](process/docs/config/qa_guidelines.md) and [agent orchestration guide](process/docs/config/agent_orchestration.md).
- Configure your own machine using the [public/private configuration guide](process/docs/config/private_configuration.md).

The process files are reusable. Example workspaces contain synthetic data; your own specs, receipts and machine configuration can live in a separate private workspace. Public application code does not require publishing your team's work history.
