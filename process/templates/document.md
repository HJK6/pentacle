# Example note

## Record

Replace this with one fact, preference or decision. For a preference, distinguish explicit instruction from inference. For a decision, state the choice, rationale and alternatives considered.

## Source and confidence

Record the source, date and uncertainty. Link the authoritative document instead of repeating an existing fact. Keep secret values and personal records outside public source.

## Revisit and evidence

Name a trigger for review if the record can change. Link any external raw evidence with its location and SHA256 in the private workspace; keep large logs/assets outside memory.
