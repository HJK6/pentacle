# Documentation baseline

Document implemented behavior for a reader without the private workspace or conversation. Explain prerequisites, installation, configuration precedence, the normal journey, failure behavior and supported optional features. Link only to public or bundled resources.

Check commands and local links against the candidate layout. Use synthetic names and values; never copy live receipts, credentials or private host profiles into examples. Report unverified setup steps explicitly. Independent documentation QA cold-reads the result against the implementation and records actionable setup or behavior defects.
